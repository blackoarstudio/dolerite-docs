# Dolerite — theme documentation

Dolerite is an Online Store 2.0 theme. Every page is built from sections you add,
reorder and remove in the theme editor, and every color, font and spacing value is a
setting rather than something baked into the code.

This documentation covers setup, every section and setting, the two product features
that need data from your admin (metafields and tags), translations, and what to do
when something does not look the way you expect.

## What is in the box

- **22 sections you can add anywhere**, in five groups: Products, Text, Media,
  Social proof and Store. See [Sections](sections.md).
- **A product page built from blocks** — 14 block types plus app blocks, in any order.
  See [Product page](product-page.md).
- **Color schemes.** Four ship with the theme; you can edit them and add more. Each
  section can sit on any scheme, so a page can alternate bands of color without you
  touching a single color value twice.
- **Three font settings**, drawn from Shopify's font library. No external font service
  is contacted when a page loads.
- **A full set of templates**: home, collection, product, cart, search, blog, article,
  page, contact page, list of collections, 404, password, gift card, and the seven
  customer account pages.
- **Six storefront languages** out of the box: English, German, French, Spanish,
  Italian and Thai.
- **A cart drawer**, quick view, predictive search, mega menus, a mobile navigation
  drawer, product filtering and sorting.

## Requirements

- A Shopify store on any plan.
- Nothing else. Dolerite needs no apps to work. It offers app blocks on the product
  page and the featured-product section, so review, subscription and upsell apps can
  add their own content where you want it.

## Conventions used in this documentation

- **Online Store → Themes → Customize** is written as *the theme editor*.
- Setting names are written exactly as they appear in the editor, in **bold**.
- Where a feature needs data from your admin rather than a setting, it says so and
  links to [Tags and metafields](tags-and-metafields.md).
